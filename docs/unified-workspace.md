# 统一调音工作区

窗口左侧是按工作流排列的侧栏，右侧整块是统一频响图。图中同时显示相对频响与数字滤波增益，频率轴、游标和缩放共用。左轴以 dB 表示相对声压／EQ 增益；打开图例中的“SPL 刻度”后，右轴显示由原始测量电平偏移得到的 SPL，两个轴保持相同 dB 比例。目标按 1 kHz 对齐，编辑和曲线显隐保留视野。

## 使用流程

侧栏五个步骤卡片各带一行状态；完成的步骤编号会高亮，卡片可以单独收起。

1. **原始频响**：导入文件（CSV／TXT／FRD／JSON／ReaLab HAR），或展开“在线测量”选择来源、品牌、型号，型号选定后自动载入。首次依据已识别设备尝试唯一匹配，此后按设备记忆；载入测量后在线选择区自动收起。打开已识别固件后，这里显示“测量对应的固件”：选择测量所对应的原固件与预设，没有准确对应关系时保留“参考关系为假定”。
2. **目标频响**：搜索在线目标库或导入文件；“设为目标”可以把当前测量（例如另一副耳机）作为目标。
3. **修正 EQ**：生成修正（RAW 或 PEQ，可设频段、强度、最大提升／衰减和平滑），或导入／导出 EQ 文本。已绑定参考时以当前固件估计为原始响应；结果整体替换现有修正，可以撤销。“参数表”打开 PEQ 与当前固件记录的停靠面板。
4. **固件预设**：打开固件后出现。在按钮组选择调音基底；适配器定义的特殊配置单独排列。内部状态、区域、采样率和模型设置位于“计算详情”。“拟合到固件预设…”在一个对话框里选择基底与写入预设（默认写入另一个预设，保留基底本身），覆盖所有输出、区域和对应状态，保留基底 HP／LP／AP。原版 Enco X4 的普通预设为四表×九状态，共 36 条；特殊配置为四条。生成后的计划列在卡片里，可以移除或撤销。
5. **导出**：编辑固件信息，或导出新固件。导出前列出全部待写入修改，需要确认“只经过离线校验，尚未实机测试”；输出为新文件，旁边保存逐路径验证报告。

“当前固件估计”对应打开的输入固件；“编辑后估计”在其上应用当前修正；“待导出估计”来自准备好的写入计划。计划保存自己的 EQ 快照，可以同时为不同目标预设准备调音。

## 图形与图例

图例即曲线开关：声学曲线（实测、估计、目标）与数字曲线（修正 EQ、DAC1、DAC2）分组显示，只列出当前可用的曲线；同样的开关在“视图 → 曲线”。DAC1（输出1）、DAC2（输出2）是显示别名，物理 DAC 编号尚未完全确认，两路可以同时叠加，开关只影响显示、不控制写入范围。“RAW 节点”控制 GraphicEQ 节点是否可见（超过 64 个节点时默认隐藏）。

标题栏的提示标签概括当前模型假设（例如“假定参考 · 双单元近似”），悬停显示完整说明。“适配”按当前可见曲线调整 dB 范围，切换测量或目标时自动适配；“复位”恢复 20 Hz–20 kHz 与默认范围。双击添加 PEQ，拖动节点调频率／增益，节点上滚轮调 Q，单击或右键打开参数浮窗，Delete 删除所选 PEQ；“?”列出全部手势。

## 外观

“视图 → 外观”（或工具栏右侧“外观”）可选择跟随系统、浅色或深色，以及四种强调色。跟随系统时，Windows 切换浅色／深色会立即生效。同一套颜色同时作用于 Qt 界面和图形；每种主题的曲线颜色单独设计，保证正文对比度不低于 WCAG AA、曲线与背景对比度不低于 3:1。设置保存在用户数据目录的 appearance.json。

## 差分模型

每路比较当前／参考数字滤波器的复数传递函数。两路比值在幅度和相位上均相同，使用共同传递变化；仅幅度相同不能证明这一关系。

两路变化不同时，当前提供互补功率权重模型：DAC1 权重 `1-w`，DAC2 权重 `w=1/(1+(fc/f)^8)`。默认交接频率 15 kHz，可修改。这是单元贡献与非相干叠加的假设，不是从整机幅度测量恢复出的实际单元声学响应。图中标出 `fc/1.4..fc*1.4` 的近似交叠区域。已有独立单元与相对相位测量时，应使用对应声学模型替换它。

默认差分仅计算滤波器；gain0/gain1 有变化时明确提示未折算。可以选择假定按 gain0 或 gain1 计入整体增益，但不会将两个字段直接相加。

已内置原版 112／116 的参考 EQ 参数模板（两版参数相同），识别 Enco X4 后默认绑定丹拿原声并标为“参考关系为假定”。如果测量条件或原固件不同，请选择对应参考固件与预设。按每条测量保存参考关系；参考数据随本地工程恢复。

## 配置映射

已知 Enco X4 通过选择／系数代码指纹和当前指针表识别。索引 45 是该适配器的规则，界面和拟合不使用固定索引。配置描述提供预设对应的表内索引、特殊配置、内部状态和输出／区域角色；实际参数地址通过导入文件的指针解析。

未知布局可在“固件 → 载入配置映射”读取 JSON。格式为 `{"layout": {...}, "configuration": {...}}`；layout 包含 bank、tables、table_names、profile_count、table_entries、flash_base（均用数值，默认是现有 300 字节／18 槽结构），configuration 包含 adapter、states、presets 和 tables。presets 每项提供 key、title、indices；特殊项提供 special=true 与一个实际索引。tables 每项提供 name、region、output。导入后的映射保存在工程中。候选扫描本身不证明特殊配置的用途。

other/india 对应滤波器在已核对的 112／116／第三方 113 中相同；india 的两个整体增益字段各高 4 dB。调音同时处理两区域，保留各自增益。以后滤波器有差异时仍按每张表的原链分别拟合。

## 剪贴板与工程历史

“复制调音”（Ctrl+Shift+C）保存完整 RAW、PEQ、启用状态和测量／目标／参考关联；“粘贴调音”（Ctrl+Shift+V）支持软件 JSON 和 Flowmix／GraphicEQ 文本。复制、粘贴也在“编辑”菜单。JSON 同时保存在文本和专用剪贴板格式中，可离线转存。参数框里的普通 Ctrl+C/V 保持文本操作。

复制按钮的菜单（或“编辑 → 复制完整固件预设”）可复制完整固件预设，包括两路、所有区域、所有状态和整体增益；已有待写入计划时复制计划内容。粘贴时选择目标预设，按目标固件重新定位记录，不携带源固件地址。状态和输出角色不兼容时需改用修正 EQ 重新拟合。目标固件的配置映射、版本等元数据保持目标工程内容。

全局撤销／重做覆盖调音、频响选择、参考关联、固件计划（包括移除计划）、粘贴与元数据；悬停撤销／重做按钮显示动作名。一次拖动、一次整体粘贴分别只记一步。曲线显隐和缩放不进入编辑历史，也不会使正在运行的拟合过期。已导出的磁盘文件不会随撤销改变。

工程 v4 保存配置、参考数据和显示选项，兼容 v1/v2/v3。

侧栏独立滚动，图形始终占满右侧高度（1028×749 窗口约 540 px）。来源索引与目标库独立加载，目标服务等待不会阻塞自动匹配和测量载入；进行中的任务在状态栏显示进度和“取消”。
